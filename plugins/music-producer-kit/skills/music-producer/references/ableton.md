# Ableton execution: official-first route pending

The former third-party trial connection was removed from the owner's PC. There is no approved replacement connection in this release.
Do not restore it, invoke its old tools, treat cached tool lists as current, or substitute a private SDK writer.
The prior successful experiment remains evidence about that experiment only.

## Before a new integration

Verify the official provider, required edition/release channel, SDK version, actual API/types and permitted distribution before implementing any adapter.
Distinguish Ableton's SDK, code built with it, MCP protocol support and Codex's actual permissions. None automatically proves the others.
Check discrete invocation, Set identity, track/clip creation, complete note read/write, device/sample loading and persistence separately. A right-click command is not proof of an external MCP endpoint.
Inspect whether note updates can preserve expressive properties; do not copy the former delete/recreate strategy into a new API.
Do not install Beta software, enroll accounts, alter the current Set or change permissions without approval. Retain existing useful kit environments.

Official public references, checked 2026-09-19:
- https://ableton.github.io/extensions-sdk/
- https://help.ableton.com/hc/en-us/articles/27303428331420-Ableton-Extensions-FAQ

The public FAQ currently specifies Live 12 Suite Beta 12.4.5 or later and discrete extension execution. The SDK/download documentation link requires an authenticated Centercode session here.
This release has not inspected the restricted API package and must not claim its save/open or external invocation methods exist or are absent.

## After an approved integration actually exists

Read the current Set and actual identifiers before writing. Decide the editable target and protected content from the request.
Use supported operations without guessing IDs, time units, fields, parameter mappings or device names. Re-read after every mutation or timeout before retrying.
Preserve original takes, range boundaries, automation, routing, note expression and relevant metadata. Incomplete observation is not evidence that omitted data stayed intact.
Keep mutable note data and device state editable. A MIDI export or rendered stem is not a Live Set.
Verify a saved new version and actual reopen using supported API or observed, approved host UI actions. Distinguish automated UI from manual intervention; don't infer persistence from a success message.
The read-only [saved-file comparison](review.md) can assist a scope review. It does not operate Live or certify external assets.
For an actual authorized MCP endpoint, [MCP discovery](mcp-connection.md) remains available. Do not run it against an SDK folder or an invented port.
