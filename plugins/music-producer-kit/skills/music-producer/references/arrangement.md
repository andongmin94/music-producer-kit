# Arrangement and production

Use musical roles to decide what is needed, not a mandatory number of tracks.
An instrument can carry a foreground melody, rhythmic support, bass, sustained harmony or an accent; roles may change by section.

## Space and density

Before adding an effect to solve masking, consider register, note density, sustain length and alternating entrances.
Do not mechanically high-pass every part or assume the same frequency bands fit every instrument.
Let one element hold attention when that serves the piece. Several competing foreground parts are an artistic choice, not always a fault.
A bigger chorus can be created by contrast with the preceding section; adding instruments is not mandatory.
An intentional repeated arrangement, fixed stereo width or flat energy profile is allowed.

## Instrument behavior

Check playable range and articulation when realistic performance matters.
MIDI velocity, note length, expression, pitch bend and sustain control are different dimensions.
Do not assume CC11 or CC74 controls the same parameter in every device; inspect the instrument's actual mapping.
A General MIDI program number is a hint to compatible players, not proof that Live has loaded a corresponding instrument.
Drum note numbers must match the actual Drum Rack or sound module. Channel 10 convention alone cannot verify this.
Start from installed Live instruments/presets and the user's available samples; scan metadata or audition only through real tools.
A Splice folder path is not itself license verification and local sample access is not permission to purchase more samples.

## Synth and sound selection

Define function, attack, sustain/release, register and tonal/noise character before tweaking a synth.
Use existing devices before proposing purchases. Describe a concrete missing capability and the attempted alternative first.
Avoid loading several synth layers with identical roles unless the blend is intentional.
Do not assume a VST parameter API also exposes its sample browser, piano roll or lyric editor.

## Mixing and evaluation

State the intended priority, depth and dynamics, then adjust measured/observed problems.
Avoid a universal LUFS target or fixed mastering chain for every request.
Check clipping, audibility, transients and mono behavior when the relevant measurements/listening path exists.
Compare versions at suitable levels; loudness differences should not automatically decide preference.
A meter can expose a technical issue but cannot certify that the song is emotionally right.
