# Music craft: select a relevant guide

A short request does not imply simple music. Protect fixed material and use theory only for delegated choices.
Lyric/vocal production is limited to Korean, English and Japanese; instrumental work does not need a language.
This language scope does not restrict the user to J-pop or three genre labels.

| Task | Guide |
|---|---|
| Harmony, chord spelling, voicing or key changes | [Harmony](harmony.md) |
| Melody, humming, development, song or loop | [Melody and form](melody-form.md) |
| Groove, drum/bass attacks, subdivision or timing | [Rhythm](rhythm.md) |
| Counterline, instruments, register or layers | [Texture and instruments](texture-instruments.md) |
| Words against music in the three supported languages | [Prosody](prosody.md) |

## Reference by feature, not stereotype

Translate a reference into the requested properties: groove, harmonic language, instrumental roles, sound palette, delivery, structure or density.
An artist name does not supply measurements of an unheard recording and does not authorize copying a melody, lyric or voice.
For fusion, identify the desired properties without assuming every convention from each source must coexist.
The following [local modules](../../../library/README.md) are available as contextual evidence, not mandatory recipes:

The table is a source map, not an exhaustive genre allowlist. For example, Latin instrumentation may support an English lyric without enabling Spanish lyric production.
Chinese-pop and Chinese-style production are excluded. Do not restore them via an archived workflow, corpus example or folk-instrument reference.
General theory written in Chinese remains evidence; the prose language does not dictate the song's language or style.
Use the local reader's default view. Read the relevant condition and exception, not all genres or the archive-audit view.

## Keep edits local

A voicing edit is not a melody rewrite. Denser drums need not change BPM. A loop does not require lyrics, a chorus or modulation.
Compare new complexity with the original instead of maximizing a checklist score.
Preserved source tables are not all independently verified; identify uncertainty where evidence is missing.
