# 설치된 플러그인의 사용자 흐름 검증

**현재 상태: BLOCKED — 공식 우선 Live 연결 미구현.**
이전 개인 MCP 시험에서 성공한 4마디·부분 수정·저장·재열기는 역사적 증거다. 현재 설치본의 새 경로가 통과했다는 뜻이 아니다.
[공식 API 확인](official-path-review.md)과 새 연결 구현, 필요한 소유자 승인을 먼저 완료한다. 옛 backend나 삭제된 도우미로 이 검사를 우회하지 않는다.

## 준비가 끝난 후 실행할 순서

새 지원 Codex 세션에서 실제 설치된 스킬의 경로·해시·버전을 확인한다. 개발 체크아웃의 별도 스크립트로 설치본 사용을 대신하지 않는다.
승인된 빈 테스트 Set만 사용하며 기존 미저장 작업은 보호한다. 사용자는 자연어만 주고 내부 계획/호출 인자는 스킬이 준비한다.

| 자연어 요청 | 기대하는 실제 증거 |
|---|---|
| 차분한 4마디 반주를 만들어줘. 화음과 베이스를 따로 편집할 수 있게 저장해. | 승인된 새 경로의 실제 호출, 현재 Set 식별, 편집 가능한 음표·장치, 새 저장 파일 |
| 베이스 두 번째 마디만 두 음으로 바꿔. 나머지는 그대로 새 버전으로 저장해. | 최신 대상 확인, 음표/클립/장치/믹서 등 보호 항목의 실제 전후 비교, 새 버전 |
| 원본과 수정본을 차례로 다시 열고 확인해. | 실제 API 또는 관찰된 UI 열기, 새 조회 결과와 저장 파일 비교. 복사한 JSON은 불가 |
| 이제 베이스 세 번째 마디만 바꿔. | 재열기 후 최신 상태로 다시 범위를 제한한 수정 |
| 이 멜로디에 한국어 가사만 붙여줘. | 가사만 작성하고 Live 연결·설치 절차를 시작하지 않음 |

4마디는 첫 시험일 뿐 제품의 최대 길이·장르 제한이 아니다.
새 API에서 지원되는 음표 수정법을 사용한다. 옛 backend의 클립 삭제/재생성이나 누락 필드를 보편 규칙으로 가져오지 않는다.
고급 연주 데이터 보존이 입증되지 않으면 임의의 기존 곡을 수정하지 않는다.

## 기록

단계별 PASS/FAIL/NOT RUN/BLOCKED, 실제 호출/설치 경로·버전, 승인 범위, 수동/자동 UI 구분과 남은 제약을 비공개 작업 폴더에 기록한다.
저장 XML 비교는 읽기 전용 보조 검사다. 실제 재열기·외부 샘플·플러그인 상태·청취의 증거와 별개다.
이 과정과 별도로 실제 들었을 때의 결과와 사용자가 만족하는지 평가한다. 코드 테스트 숫자로 음악 품질을 판정하지 않는다.
공개 레포에는 개인 경로·녹음·실제 곡·원시 호출 로그를 넣지 말고, 가린 요약만 전달한다.
