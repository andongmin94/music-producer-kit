# Windows 다음 단계 — 재설치가 아니라 공식 경로 확인

이전 제3자 MCP 실험은 성공 후 제거되었다. 현재 대체 연결·공식 SDK·Live Beta 설치 완료로 기록하지 않는다.
우선 [공식 경로 확인 요청](official-path-review.md)을 로컬 Codex에 전달한다.
읽기 전용으로 현재 호환 조건과 이미 확보한 SDK 자료를 확인하고, 필요한 자료/승인만 정확히 분리한다.
기존 곡을 열고 닫거나, 제거한 서버를 복구하거나, Beta를 자동 설치하지 않는다.

패키지·MIDI 검사는 [로컬 검사](local-smoke-test.md)에서 계속 수행할 수 있다.
[설치된 사용자 흐름 검증](installed-flow-acceptance.md)은 새 연결을 구현한 이후에만 실행한다.
