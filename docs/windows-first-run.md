# Windows 실행 위치

2026-09-19 실제 PC 연결·4마디 편집·UI 저장/재열기는 완료했다. 그 결과는 [인계문](web-handoff.md)에 기록되어 있다.
서버를 다시 선정하거나 설치하는 것이 다음 단계가 아니다.

현재 로컬 Codex가 할 일은 [설치된 플러그인 사용자 흐름 검증](installed-flow-acceptance.md)이다.
기존 ableton_live와 이미 정상 동작한 데스크톱 core를 재사용하고, 설치된 0.7.0 스킬이 새 네이티브 도구 세션에서 자연어 요청을 끝까지 처리하는지 확인한다.

패키지 파일 자체는 [로컬 검사](local-smoke-test.md), 실제 제작 절차는 [번들 Live workflow](../plugins/music-producer-kit/skills/music-producer/references/live-workflow.md)를 따른다.
개인 workspace, 연결 설정, 실제 음악과 호출 로그는 공개 저장소에 넣지 않는다.
