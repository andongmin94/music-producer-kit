# 현재 원본 선별 범위

## 0.5.0: 제외한 자료는 원본도 남기지 않는다

중국 특화 자료는 사용 중지나 숨김이 아니라 **현재 보관 파일에서도 삭제**했다.
원본 두 저장소의 전체 ZIP을 없애고, 남길 자료만 담은 composition-selected.zip과 lyrics-selected.zip으로 교체했다.
현재 보유 범위는 **41개 모듈 / 89개 파일 / 1,805,308바이트**다. 외부 원본이 사라져도 이 선별 자료는 남는다.

삭제 대상은 중국어·광둥어·중국풍·협음 전용 모듈 5개와 중국 곡 분석 중심의 사례 모듈, 중국 민속악기 파일, 중국 가사·퓨전 예제다.
공통 악기·힙합·작사·운율 문서에 들어 있던 해당 전용 절과 연결도 정리했다. 불필요한 원본 설치 등록정보와 중복 홍보 README도 보관 대상에서 제외했다.
범용 음악이론은 원문이 중국어라는 이유로 버리지 않았다. 한영일 발음과 일본어 한자도 그대로 다룬다.

[삭제·편집 내역](SOURCE_SELECTION_REPORT.json)은 경로와 처리 결과만 기록하며 삭제한 본문을 담지 않는다.
[단일 자료 목록](../plugins/music-producer-kit/library/catalog.json)은 실제 남긴 파일과 그 해시를 기록한다. 편집 파일은 원본 해시·유지한 원본 줄 범위도 구분한다.
별도 중복 목록과 과거 전체-스냅샷 보고서는 삭제했다. 전체 원본을 보존했다는 이전 설명은 현재 버전에는 적용되지 않는다.

## 사용 및 검증

기본/감사용 이중 모드가 없다. list/read/find/outline은 실제 존재하는 같은 선별 자료만 다룬다.
없는 파일은 오류이며 원격 복구, 호환 경로, 원본 자동 설치를 제공하지 않는다.
이관 지침의 source 줄 위치도 새 선별본에 맞췄다. 삭제 부분을 빈 줄로 남겨 옛 위치를 유지하지 않는다.
새 ZIP 내부 파일 목록·바이트·해시와 삭제 대상의 부재를 검사한다. 배포 ZIP 안의 중첩 자료도 확인한다.
원저의 학술적 타당성이나 음악적 품질 전부를 검증했다는 뜻은 아니다.

## Git 이력 및 권리

변경 대상은 현재 Git 트리와 신규 배포물이다. 이미 생성된 과거 커밋·기존 복제본·예전 배포물을 소급 삭제했다고 주장하지 않는다. 이 작업은 force-push나 이력 재작성을 하지 않는다.
LICENSE와 NOTICE는 출처 고지이므로 원문대로 남겼다. 고지문에 과거 주제가 언급되는 것은 제작 자료 보관이 아니다.
제3자 인용물까지 새 라이선스로 일괄 허가하지 않는다. [NOTICE](../plugins/music-producer-kit/NOTICE.md)를 확인한다.
