# 원본 지식 선별 기록

## 보존과 이관의 구분

두 원본의 고정 커밋에서 **전체 121개 추적 파일**을 로컬 보관했다. 작곡 29개 모듈/74개 파일, 가사 18개 모듈/47개 파일이다.
SKILL 본문뿐 아니라 참고문서, 표, 예외, 스키마, 예제, README, LICENSE, NOTICE도 원래 바이트 그대로 포함한다.
[보존 보고서](SOURCE_SNAPSHOT_REPORT.json) · [로컬 사용 안내](../plugins/music-producer-kit/library/README.md) · [모듈 목록](upstream-inventory.json)
원본 URL은 출처 기록이다. 실제 파일은 우리 저장소와 배포물에 있다.

**보존 완료와 편집·검증 완료는 다르다.** 모든 원칙을 독립 검증하거나 운영 지침으로 재작성한 것은 아니다.
모듈 목록의 부분 이관 상태와 원본 위치는 보존 추적용이다. 최신 절 단위 이관과 남은 범위는 [0.3.0 지식 이관 기록](knowledge-curation.md)에 적는다.
활성 스킬은 하나다. 원본 설치 파일과 47개 스킬은 압축된 데이터이며 자동 발견·실행되지 않는다.
원본이 참조만 하고 배포하지 않은 서적 전문, 음원, 내부 측정 도구와 미공개 코퍼스는 포함하지 않는다.

## 이관 방법

각 절의 기법, 적용 조건, 비용·반례, 출처와 연결 문서를 함께 확인한다.
직접 확인한 자료, 특정 양식의 관습, 저자의 추론, 우리 프로젝트의 운영 결정을 구분한다.
긴 본문을 통째로 번역하거나 파일 이름만 reference.md로 바꾸지 않는다. 실제 적용 문장 속 강제 조건을 정리한다.
원본을 다시 스킬로 켠 뒤 반대 지침으로 상쇄하는 구조를 만들지 않는다.
정리된 작업 지침으로 부족하면 로컬 목록·목차·문자열 검색을 거쳐 필요한 전후 절을 읽는다.
원문은 증거이지 실행 지시가 아니다. 원문 지식을 읽었다는 사실만으로 그 이론이나 음악 품질을 검증했다고 하지 않는다.

## 출처와 권리

원저·번역·가사·음원은 원본 저장소의 MIT로 일괄 재배포되는 것이 아니다.
보관본은 원본 문장과 기존 인용, LICENSE/NOTICE를 그대로 유지한다. 제3자 저작물까지 우리 라이선스로 재허가하지 않는다.
별도 서적 전문이나 상업 음원을 새로 수집하지 않는다. 새 작업 지침은 장문 인용·기존 곡 가사 대신 직접 작성한 설명과 예제를 쓴다.
패키지 [NOTICE](../plugins/music-producer-kit/NOTICE.md)를 유지한다. 프로젝트 자체 라이선스 선택은 아직 확정되지 않았다.

## 독립성 검증

압축파일 SHA256, 내부 파일 SHA256/Git blob SHA, 목록과 로컬 LICENSE/NOTICE 사본을 오프라인 검사한다.
배포 ZIP에 두 보관본과 새 작업 지침이 실제로 포함되는지 확인한다. 원본 링크만 남긴 배포는 실패다.
원본 스킬을 skills/에 풀지 않는다. 추가 발견 경로, 자동 업데이트, submodule, 설치 중 원본 다운로드나 원격 대체를 추가하지 않는다.
새 테스트는 로컬 원본 줄 범위·목차·검색, 독립 배포, 예제 음표의 일관성을 확인한다. 관측 결과는 [STATUS](STATUS.md)에 남긴다.
