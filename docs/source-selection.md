# 원본 지식 선별 기록

## 0.5.0: 보관하지 말라는 자료는 실제로 제거

중국 전용 원본을 보관할 필요가 없다는 소유자의 최신 지시가 과거의 전체 보존 방침을 대체한다.
현재 저장소와 설치 패키지에는 선별본만 남기며, 원본 ZIP·숨겨진 보관 모드·조회 우회 옵션을 두지 않는다.
[현재 선별 보고서](SOURCE_SELECTION_REPORT.json)에는 삭제 파일명과 삭제 줄 범위만 기록한다. 삭제한 본문을 보고서에 복사하지 않는다.
[모듈 목록](upstream-inventory.json)도 실제 남은 모듈만 기록한다.

## 제거 범위

mc-style-chinese-pop, lw-mandarin, lw-cantonese, lw-chinese-style, lw-tone-check 전용 디렉터리를 삭제했다.
mc-orchestration/reference-minyue.md 및 중국풍 결합 예제를 삭제했다.
원본 플러그인 설치 메타데이터와 루트 소개 문서는 지식 자료로 재배포하지 않는다. LICENSE/NOTICE는 그대로 보존한다.
공통 문서에서는 지정한 중국 특화 제목 아래의 절, 관련 문단·표 행·전용 참조를 제거했다.
원래 줄 위치를 추적할 필요가 있는 삭제 부분은 빈 줄이며 원문 복구 데이터가 아니다.

## 남기는 범위

범용 화성·리듬·곡 구조·서양 악기·음색·작사 기법, 비배제 장르, 한국어·영어·일본어를 남긴다.
본문이 중국어라는 이유로 일반 음악이론을 전부 폐기하지 않으며, 일본어 한자도 삭제하지 않는다.
문자 범위로 언어를 단정하는 필터를 사용하지 않는다. 출처의 작성 언어와 음악 제작 분야는 별개다.
새 선별본은 원본 전체와 바이트가 같다는 주장을 하지 않는다. 현재 파일 해시와 원래 출처 해시를 분리해 기록한다.

## 검증과 남은 한계

검사는 실제 ZIP 내부 파일과 본문을 읽어 지정한 전용 자료·주제 표현의 부재, 남은 자료의 해시·출처·접근을 확인한다.
이것은 임의의 모든 문화적 관련성을 판정하는 의미 분석기나 모든 문장의 학술 검증이 아니다.
추가로 발견되는 범위 밖 본문은 다시 숨기는 대신 삭제한다. 부재한 자료를 원격이나 이전 버전에서 자동 복원하지 않는다.
원문 지식의 조건·예외·출처는 보존하되 음악적 취향을 강제 규칙으로 바꾸지 않는다.

기존 Git 커밋 이력은 강제 재작성하지 않았다. 현재 트리와 새 설치 패키지에는 제거가 적용되며, 과거 버전이 자동으로 바뀌는 것은 아니다.
[현재 상태](STATUS.md)에 실제 검사 결과와 미검증인 Codex/Live/청취 작업을 구분해 기록한다.
