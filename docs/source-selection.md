# 원본 지식 선별 기록

## 보존과 제작 범위

두 원본의 전체 121개 추적 파일은 고정 커밋의 원래 바이트로 보존한다. 작곡 29개 모듈/74개 파일, 가사 18개 모듈/47개 파일이다.
참고문서·표·예외·스키마·예제·README·LICENSE·NOTICE를 포함한다. 원본이 배포하지 않은 책 전문, 음원, 내부 도구와 코퍼스는 포함하지 않는다.

## 0.4.0: 소유자가 확정한 범위

가사·보컬 제작은 한국어, 영어, 일본어와 그 혼합이다. 연주곡에는 언어를 요구하지 않는다.
중국어·광둥어 및 중국 특화 제작을 활성 경로와 향후 이관 목표에서 제외한다. 중국어로 쓰인 범용 음악이론은 유지한다.
일본어 한자나 차용어를 글자 모양만 보고 중국어로 판정하지 않는다.

| 원본 항목 | 현재 처리 |

| 나머지 비배제 장르와 범용 기법 | 보존하고 현재 요청에 필요한 것만 사용 |

기본 조회는 42개 모듈, 전체 백업은 47개 모듈이다. 완전 보존과 선택적 사용을 혼동하지 않는다.
유지관리자는 명시적 archive audit으로 원문을 확인할 수 있다. 제작 거절 시 자동 대체 경로로 사용해서는 안 된다.
차단은 모듈/파일 수준이다. 혼합 목적의 원문을 모두 문장 단위로 정제했다는 뜻은 아니므로, 범용 자료 속 중국 특화 지침도 실행 규칙으로 승격시키지 않는다.

## 계속 유지하는 이관 원칙

화성·보이싱·텐션, 멜로디와 동기 발전, 리듬·음역·텍스처, 가사와 음표 연결, 보컬 표현은 계속 보강한다.
각 기법의 적용 조건·비용·반례·출처를 함께 옮긴다. 파일 제목이나 원문의 작성 언어만 보고 범용 지식을 버리지 않는다.
기술 불변 조건과 미적 권고를 분리한다. 전조·비대칭·후렴 변화·피치 흔들림은 보편 합격 조건이 아니다.
원본 워크플로를 켠 뒤 반대 지시로 상쇄하지 않는다. 실제 사용하는 지침을 수정하고 오래된 언어 확장 경로를 제거한다.
전체 문장·표의 검수나 원저 독립 검증은 미완료다. 최신 내용과 남은 범위는 [지식 이관 기록](knowledge-curation.md)에 적는다.

## 출처·권리·검사

원본은 인용과 LICENSE/NOTICE를 유지한다. 제3자 책·번역·가사까지 우리 라이선스로 재허가하지 않는다.
새 지침은 직접 작성한 설명과 예제를 사용한다. 별도 서적 전문이나 상업 음원은 수집하지 않는다.
[NOTICE](../plugins/music-producer-kit/NOTICE.md)를 유지한다. 프로젝트 자체 라이선스는 아직 확정하지 않았다.
압축파일 SHA256·파일별 SHA256/Git blob SHA·권리 고지를 네트워크 없이 검증한다.
배포물에서도 기본 범위 제한과 세 언어 문서가 유지되어야 한다. 원본 누락 시 외부 다운로드로 복구하지 않는다.
정적 검사는 실제 모델 행동, 언어 자연스러움이나 음악 품질을 증명하지 않는다. [STATUS](STATUS.md)에 실제 관측만 기록한다.
