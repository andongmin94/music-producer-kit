# 원본 지식 선별 기록

## 의미와 범위

[전체 47개 모듈 목록](upstream-inventory.json)은 고정 커밋별 보존·이관 상태를 기록한다.
29개 작곡 모듈과 18개 가사 모듈을 목록에 남겼다. 원문 전체를 패키지에 복사하거나, 모든 책의 출처를 검증했다는 뜻은 아니다.
`deferred-preserve`는 아직 세부 검토하지 않았으며 원본 디렉터리와 참조 링크를 보존한다는 의미다. 불필요하다고 삭제한 것이 아니다.
새 활성 참고문서는 간단한 범용 요약이다. 전문 표·악기별 기술·언어별 예제의 전체 이관은 후속 작업이다.

## 다음 이관 원칙

제목만 보고 삭제하지 않는다. 장르·뮤지컬·대위법 문서에도 다른 용도로 옮길 기법이 있을 수 있다.
각 절을 옮길 때 적용 조건, 반례/비용, 출처, 연결된 참고문서를 함께 확인한다.
주장을 직접 확인한 사실, 특정 양식의 관습, 저자의 추론, 이 프로젝트의 운영 제안으로 구분한다.
원본 SKILL.md를 reference.md로 이름만 바꾸지 않는다. 문장 속 강제조건도 정리한다.
원본 두 팩과 수정본을 동시에 활성화해 반대 지침으로 상쇄하지 않는다.
