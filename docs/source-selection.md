# 원본 지식 선별 기록

## 의미와 범위

두 원본의 고정 커밋에서 **전체 121개 추적 파일**을 로컬 보관했다. 작곡 29개 모듈/74개 파일, 가사 18개 모듈/47개 파일이다.
SKILL 본문뿐 아니라 참고문서, 표, 예외, 스키마, 예제, README, LICENSE, NOTICE도 원래 바이트 그대로 포함한다.
[보존 검증 보고서](SOURCE_SNAPSHOT_REPORT.json)와 [오프라인 사용 안내](../plugins/music-producer-kit/library/README.md)를 확인한다.
[모듈 목록](upstream-inventory.json)의 `local_archive`는 우리 저장소 파일을 가리킨다. 원본 URL은 출처 기록일 뿐이다.

**보존 완료와 편집·검증 완료를 구분한다.** 원문 전체는 확보했지만 모든 원칙을 검증하거나 운영 지침으로 재작성한 것은 아니다.
`local-source-not-yet-adapted`는 원문이 로컬에 있고 세부 편집이 남았다는 뜻이다. 외부 링크만 남았다는 뜻이 아니다.
활성 스킬은 하나다. 원본의 설치 파일과 47개 스킬은 압축된 데이터이며 자동 발견/실행되지 않는다.
선별된 참고문서로 부족한 경우 로컬 읽기 도구로 필요한 절만 읽는다. 원문 속 명령·게이트를 새 제작 지시로 실행하지 않는다.
원본 두 저장소가 비공개화되거나 삭제되어도 이 파일들은 우리 Git 기록과 설치 패키지에 남는다.
원본이 참조만 하고 배포하지 않은 서적 전문, 음원, 내부 측정 도구와 미공개 코퍼스는 포함하지 않는다.

## 다음 이관 원칙

제목만 보고 삭제하지 않는다. 장르·뮤지컬·대위법 문서에도 다른 용도로 옮길 기법이 있을 수 있다.
각 절을 옮길 때 적용 조건, 반례/비용, 출처, 연결된 참고문서를 함께 확인한다.
주장을 직접 확인한 사실, 특정 양식의 관습, 저자의 추론, 이 프로젝트의 운영 제안으로 구분한다.
원본 SKILL.md를 reference.md로 이름만 바꾸지 않는다. 문장 속 강제조건도 정리한다.
원본 두 팩과 수정본을 동시에 활성화해 반대 지침으로 상쇄하지 않는다.

## 출판과 권리

인용된 원저·번역·가사·음원은 원본 저장소의 MIT 라이선스로 일괄 재배포되는 것이 아니다.
보관본에는 원본 저장소의 문장과 기존 인용이 그대로 포함된다. 원본 LICENSE/NOTICE도 함께 보존하며 인용된 제3자 저작물까지 우리 라이선스로 재허가하지 않는다. 별도 서적 전문이나 상업 음원을 새로 수집하지 않는다.
패키지의 [NOTICE](../plugins/music-producer-kit/NOTICE.md)를 함께 유지한다.
소유자의 프로젝트 라이선스 선택은 아직 확정하지 않았다.

## 독립성 검증

각 압축파일 SHA256, 내부 파일 SHA256/Git blob SHA, 파일 목록, 로컬 LICENSE/NOTICE 사본을 오프라인으로 검사한다.
배포 ZIP에 두 원본 보관본이 모두 들어 있어야 한다. 원본 링크만 있는 배포는 실패다.
원본 스킬 파일을 실제 `skills/`에 풀어 넣지 않는다. 추가 자동 실행 경로도 만들지 않는다.
자동 업데이트, Git submodule, 설치 중 원본 다운로드, 누락 시 원격 대체 경로는 두지 않는다.
