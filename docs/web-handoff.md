# Music Producer Kit — 공식 우선 인계

갱신일: 2026-09-19. 현재 교정 버전: 0.7.1.
근거 입력은 소유자가 제공한 music-producer-kit-web-handoff-20260919-official-first.zip이다.
입력 SHA256: `ef745c6d0f50d7f1b4dca98ca5ac6b412ce1268e901f0fa62c94b58a323d0bb7`.
그 ZIP은 0.6.0 코드에 새 결정을 담았으므로 전체 덮어쓰지 않는다. 이번 변경은 0.7.0 구현 위에 그 결정을 반영했다.

## 목표와 최신 결정

제품은 자연어로 Ableton에서 곡 전체를 만들거나 지정 부분만 수정하고, 편집 가능한 원본을 저장·재열기하는 Codex 플러그인이다.
4마디는 연결 시험이지 최종 제품이 아니다. 한영일 및 혼합 가사/보컬, 연주곡과 다양한 장르를 유지한다. 취향·언어 인터뷰를 반복하지 않는다.
소유자는 개인 배포 MCP를 계속 기반으로 쓰는 데 동의하지 않았고 Ableton 공식 제공 경로 우선을 요구했다. 이전 시험 backend의 계속 사용 권고는 철회되었다.

## PC의 현재 상태 — 첨부에서 보고한 내용

이전 nicholasbien/ableton-mcp-pro 시험 설치를 제거했다. Codex ableton_live 항목, Live Control Surface 설정, 리스너/서버 프로세스를 정리했다.
설치 manifest의 경로·소유권·해시를 확인한 뒤 시험 때 추가한 서버/환경·Remote Script 폴더만 제거했다.
테스트 Set과 비공개 증거는 보존했다. 현재 사용자의 Set은 저장하거나 닫지 않았다.
대체 MCP, 공식 SDK, Live Beta는 아직 설치하지 않았다. 제거한 이전 설치를 복구하지 않는다.

## 이전 실험과 현재 완료 판정의 구분

이전 Live 12 Suite 12.4.6 실험에서는 네이티브 Codex 읽기 1회, 별도 SDK 경로로 4마디 작성과 Bass 한 마디 수정, 실제 UI 자동 저장·재열기를 검증했다.
그 결과와 실제 .als 비교는 [STATUS](STATUS.md)에 역사적 증거로 보존한다. 새 공식 경로의 성공이나 설치 스킬의 전체 사용자 흐름 증거가 아니다.
공식 SDK, SDK 위의 우리/제3자 코드, MCP 클라이언트/서버를 구별한다. 공식 SDK 사용만으로 코드 공급자가 Ableton이 되지 않는다.

## 보존과 제거

단일 스킬, 41모듈/89파일의 선별 지식, Mido, SoundFile, 일반 MCP 조회 도구, 저장 파일 비교와 법적 고지는 보존한다.
0.7.1에서 이전 MCP 도구/응답에 종속된 작성기와 작업 절차는 실제 삭제했다. 호환 옵션이나 비활성 fallback은 두지 않는다.
저장 .als 비교는 독립시켰다. XML 비교는 실제 호스트의 재열기나 외부 샘플/플러그인 검증을 대신하지 않는다.
중국 특화 원본·숨긴 보관본·자동 복구는 되살리지 않는다. 일반 중국어 음악이론과 일본어 한자는 유지한다.

## 다음에 할 일

1. AGENTS.md, STATUS.md, requirements.md와 [공식 경로 확인](official-path-review.md)을 읽는다.
2. 현재 Live의 에디션·릴리스 채널과 확보한 공식 SDK 문서·타입·예제·라이선스를 먼저 확인한다. 웹에서 상세 SDK 다운로드는 Centercode 세션이 필요했다.
3. 정확한 실행 진입점, 대상 식별, 생성/음표 수정, 장치/샘플, 저장/재열기, 배포 조건을 확인하고 연결 하나만 구현한다. 없는 API를 추측하거나 옛 삭제/재생성 방식을 이식하지 않는다.
4. 필요한 Beta/패키지 설치와 계정·설정 변경은 별도 승인을 받는다. 자료 확보와 설치는 다른 단계다. 현재 곡은 건드리지 않는다.
5. 구현 뒤 [설치본 흐름](installed-flow-acceptance.md)을 실제 로컬 Codex에서 실행한다. 자연어 작성→좁은 수정→보호 비교→저장·재열기→연속 수정이 필요하다.

로컬 PC가 필요한 실제 실행과 자료 접근만 로컬에 맡긴다. 이미 있는 범용 구현을 갈아엎거나 문서만 늘려 완료를 대신하지 않는다.
개인 경로·자격증명·유료 샘플·미공개 곡·원시 로그·SDK 전문은 공개 레포에 넣지 않는다. 공유 권한과 개인정보를 검토한 요약만 전달한다.
패키지 테스트, 모델 실행, 새 Live 연결, 청취 품질은 서로 다른 검증이다. 고정 false 플래그를 true로 고쳐 성공을 만들지 않는다.
