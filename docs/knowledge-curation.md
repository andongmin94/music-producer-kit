# 지식 이관 기록

## 0.5.0 — 불필요한 원본 제거와 보유 샘플 활용

중국 전용 원본을 포함한 전체 보관본을 유지하던 0.4.0 방침을 폐기했다.
현재는 한국어·영어·일본어와 범용 음악 제작 지식을 선별해 보유한다. 원문 감사 모드나 복구용 원본 ZIP은 없다.
삭제 내역은 [선별 보고서](SOURCE_SELECTION_REPORT.json)에 파일명·줄 범위로 기록하며 삭제 본문은 재배포하지 않는다.
전용 모듈 삭제에 그치지 않고 공통 문서의 지정된 특화 절·문단·행도 정리했다. 범용 이론과 일본어 한자는 보존한다.

## 유지하는 제작 지식

| 영역 | 사용하는 지식 |
|---|---|
| 화성 | 화음·보이싱·텐션·차용·전조와 보호할 멜로디/베이스의 구분 |
| 멜로디·구조 | 흥얼거림의 특징, 반복·변형·확장·재현, 노래와 반복 BGM |
| 리듬 | BPM·세분·강조·미세 타이밍, 킥/베이스 관계, 시간 계산 |
| 악기·텍스처 | 역할·음역·밀도·혼합·분리·대선율·보유 음원 선택 |
| 가사·발음 | 의도·운율·문구 보호, 문자·음절·모라·음표 구분, 한영일 구절별 적용 |
| 보컬 | 가이드·녹음·합성 구분, 표현·화음·더블·교정 범위 |

기술적 불변 조건과 미적 권고를 분리한다. 정확한 리듬, 같은 후렴, 온음계 화성, 일정한 BGM을 결함으로 취급하지 않는다.
일곱 핵심 작업 안내와 세 언어 안내는 부분 이관이다. 모든 심화 표·원저 주장·언어 표현을 검증한 것은 아니다.
선별본 안에서 실제로 남은 내용만 참고하고 삭제된 절의 출처 위치를 검증된 설명으로 인용하지 않는다.

## 다음 실행 도구: 보유 샘플 찾기

[samples.md](../plugins/music-producer-kit/skills/music-producer/references/samples.md)와 표준 라이브러리 기반 sample_library.py를 추가했다.
허용된 폴더 안의 음원 후보를 이름/경로로 검색하고, 상대 경로·크기·SHA256을 돌려준다. 읽기만 하며 구매·업로드·파일 변경은 없다.
WAV/FLAC/AIFF/OGG 등은 확장자 후보 인식이다. 실제 디코딩·BPM/조성 분석·청취·품질 평가를 했다는 뜻이 아니다.
샘플이 발견되었다고 Ableton에 로드되었다고 보고하지 않는다. 실제 로딩과 저장은 MCP 기능을 확인한 뒤 검증해야 한다.

## 다음 검증

상세한 악기·편곡·음색 지식은 현재 작업에 필요한 만큼 계속 이관한다.
우선 로컬 Windows/Codex에서 스킬 활성화와 실제 MCP 기능을 확인하고, 편집 가능한 Live Set 생성·저장·재열기·부분 수정으로 이어져야 한다.
코드 테스트와 원문 검색 성공은 실제 모델 행동·가창 자연스러움·음악 품질의 증거가 아니다.
실제로 실행한 결과만 [STATUS](STATUS.md)에 적는다.
