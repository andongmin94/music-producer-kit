# 지식 및 실행 기능 이관

## 현재 기준

가사·보컬은 한국어·영어·일본어와 혼합 가사, 음악은 비배제 장르 전반이다. 연주곡은 언어를 요구하지 않는다.
중국 특화 자료는 원본도 현재 패키지에서 삭제했다. [선별 기록](source-selection.md)이 최신 보유 범위다.
이전 전체 원본 보존·감사 모드의 설명은 폐기했다. 원본 47개를 전부 보관하거나 전부 검수했다는 주장을 하지 않는다.

## 유지한 지식

화성, 멜로디/구조, 리듬, 텍스처/악기, 작사, 공통 prosody, 보컬 제작의 작업 지침과 세 언어의 상세 지침을 유지한다.
일반 화성학·서양 관현악·신스·비배제 장르·랩의 기법과 예외는 필요한 범위만 로컬 자료에서 읽는다.
원문이 중국어인 일반 이론은 배제 주제와 다르다. 문자 모양으로 일본어 한자를 차단하지 않는다.
기술 불변 조건과 미적 관습은 구분한다. 전조·비대칭·같은 후렴의 변경·타이밍 흔들림을 전곡 필수 조건으로 두지 않는다.

## 이번의 다음 실행 단계: 실제 보유 샘플 조회

[샘플 지침](../plugins/music-producer-kit/skills/music-producer/references/samples.md)과 sample_library.py를 추가했다.
사용자가 지정한 로컬 폴더에서 오디오 헤더를 읽고 사적인 JSON 목록을 만든다. 이름 검색 후 선택한 파일을 재확인하고 SHA256을 계산할 수 있다.
WAV의 정수 PCM뿐 아니라 부동소수점 WAV, FLAC, AIFF 등의 해석은 SoundFile에 맡겼다. 파일 포맷 파서를 직접 만들지 않는다.
파일 이름에 120이나 C가 있어도 BPM이나 조성으로 확정하지 않는다. 파일이 있다는 이유로 Splice 라이선스를 검증했다고 하지 않는다.
원본 오디오는 수정·재생·업로드하지 않는다. 이 기능은 유사음 검색, 자동 청취, 믹싱, Splice 계정 조작 또는 Live 로딩 도구가 아니다.

## 아직 남은 검증

실제 사용자 환경의 Codex 스킬 활성화, Ableton MCP 도구 읽기, Live 생성/저장/재열기/범위 제한 수정, 청취 검증은 별도다.
샘플 검사는 직접 만든 작은 오디오 fixture로 수행하며 사용자 샘플을 읽었다고 주장하지 않는다.
행동 시나리오 정의는 실제 Codex 실행이 아니다. 실제 결과는 [STATUS](STATUS.md)에 기록한다.
