# 지식 이관 기록

## 0.4.0 — 한국어·영어·일본어에 집중

소유자는 가사·보컬 권역을 한국어/영어/일본어로 정했고 중국 특화 제작을 제외했다.
이 결정은 사용자 인터뷰의 미해결 항목이 아니라 확정된 제품 범위다. 세 언어 안에서는 곡마다 선택하고 서로 섞을 수 있다.
J-pop만 남긴다는 뜻이 아니며, 연주곡에는 가사 언어를 강제하지 않는다.

## 이번 변경

| 변경 | 실제 처리 | 검증의 한계 |
|---|---|---|
| 범위 일관성 | 진입 스킬, 요구사항, README, 개발 계약, 가사/장르 인덱스를 한영일 기준으로 수정 | 문서만으로 LLM 준수를 보장하지 않음 |
| 중국 특화 자료 분리 | 기본 조회에서 5개 전용 모듈과 중국 민속악기 전용 파일 제외 | 범용 원문의 개별 문장까지 자동 분류/삭제하는 기능은 아님 |
| 백업 보존 | 전체 47개 모듈·121개 파일과 원래 해시 유지 | 확보되지 않은 책·음원·내부 도구는 새로 얻지 않음 |
| 언어별 지침 | 공통 prosody에서 한국어·영어·일본어 문서로 해당 언어만 선택 | 원어민 가창 평가나 자동 발음 분석기는 아님 |
| 혼합 가사 | 각 구절의 실제 가창 언어와 읽기를 분리하고 한 구간 지도를 공유 | 한자·로마자 모양으로 언어를 자동 판정하지 않음 |
| 검사 | 기본 접근 차단, 명시적 유지관리 읽기, 백업 무결성, 독립 배포, 로컬 출처 위치 검사 | 모델 시나리오 실행·음악 품질 증거가 아님 |

기본 제작 목록은 42개 모듈이다. 제외 항목의 정확한 목록은 [선별 기록](source-selection.md)과 [로컬 라이브러리 안내](../plugins/music-producer-kit/library/README.md)에 있다.
명시적인 archive audit은 유지관리용 원문 점검이며, 제작 범위를 되살리는 fallback이 아니다.
중국어로 적힌 일반 화성학은 계속 읽을 수 있다. 같은 문서에 섞인 중국 음악 전용 사례를 따르라는 지침은 아니다.

## 세 언어 작업 문서

[한국어](../plugins/music-producer-kit/skills/music-producer/references/lyrics-korean.md)는 표기와 실제 읽기, 받침/연음, 축약, 모음 지속과 자음 닫기, 고정 가사/멜로디의 보호를 다룬다.
받침이 있다는 이유로 단어를 자동 교체하거나 장음을 금지하지 않는다.

[영어](../plugins/music-producer-kit/skills/music-producer/references/lyrics-english.md)는 음절·단어 강세·구절 강조를 구분한다.
약한 음절에도 시간이 필요하며, 기능어가 강조될 수 있고 한 음절이 여러 음에 걸칠 수 있음을 다룬다.

[일본어](../plugins/music-producer-kit/skills/music-producer/references/lyrics-japanese.md)는 한자 표기와 읽기, 모라·장음·촉음·발음(撥音), 음표와 가창 타이밍을 구분한다.
한 모라를 한 MIDI 음표에 무조건 대응시키지 않고 일본어 한자를 중국어로 오인하지 않는다.

영어 강세·연결 발음과 일본어 모라의 기초 구분은 British Council, Tokyo University of Foreign Studies, Japan Foundation의 직접 교육자료와도 대조했다.
필요한 요지는 문서 안에 정리했고 외부 주소는 검증 출처이지 실행 의존성이 아니다. 자료의 발음 설명을 가창의 절대 규칙으로 확대하지 않는다.
한국어의 이번 범위는 보관본의 검토된 절과 직접 작성한 설명을 보강한 것이며 별도 발음 사전 전수 검증은 아니다.

## 0.3.0에서 유지하는 기반

화성, 멜로디/구조, 리듬, 텍스처/악기, 작사, 공통 prosody, 보컬 제작의 일곱 영역을 유지한다.
동일 후렴·정확한 타이밍·온음계 화성·안정된 BGM을 결함으로 취급하지 않는다.
[4마디 화성/베이스 예제](../plugins/music-producer-kit/skills/music-producer/examples/harmony-study.json)와 Mido 생성/지정 구간 편집은 변경하지 않았다.
로컬 source_library.py의 목록·목차·문자열 검색·줄 범위 읽기도 유지하며 범위 선택을 추가했다. 새 서버·의존성·상시 CI를 늘리지 않았다.

## 남은 이관 범위

일반 악기별 음역·연주법, 서양 관현악, 심화 화성·전조·대위법·구조, 음색 설계, 비배제 장르, 한영일 운율의 세부 사례는 계속 필요한 만큼 검토한다.
중국어/광둥어 상세 작사·협음, 중국풍 장르, 중국 민속악기 심화 이관은 이 목록에서 제거했다.
원본 전체 보존은 완료지만 모든 허용 범위의 문장과 표가 독립 검증·재작성되었다고 주장하지 않는다.
