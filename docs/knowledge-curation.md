각 문서 말미에 **실제로 검토한 로컬 원본의 모듈·파일·줄 범위**를 적었다.
이 표는 모든 원저의 페이지·연구 결과를 독립 검증했다는 뜻이 아니다. 원저의 상세 출처는 보관본에 유지한다.
수치·음표 예제와 작업 보호 절차는 이 프로젝트의 새 설명이며, 원본 음원이나 가사를 베끼지 않는다.

## 원본을 반대 지침으로 덮는 대신 실제 사용 지침을 수정

과거 원본에는 후렴의 동일 반복을 권하는 설명과 금지하는 검사표가 함께 있었다.
우리 지침은 반복 자체를 결함으로 분류하지 않고 요청과 맥락에 따라 선택하도록 통일했다.
가사 공통 명세의 중국어 글자 계산을 다국어 공통 검사로 쓰지 않는다.
음절 수와 음표 수가 같다는 가정을 제거하고 실제 읽기와 배치를 함께 확인한다.
기술적 불변 조건과 음악적 관습을 분리한다. MIDI 범위·저장 파일·보호 이벤트 검사는 필수이지만, 전조·비대칭·에너지 하강은 모든 곡의 합격 조건이 아니다.

## 원본 상세표를 더 쉽게 찾는 도구

기존 source_library.py 안에 outline과 find를 추가했다. 새 검색 서비스·인덱스 서버·벡터 DB·네트워크 의존성은 없다.
outline은 코드 블록을 제외한 ATX 제목과 줄 번호를 반환한다. 완전한 Markdown 파서라고 주장하지 않는다.
find는 선택한 모듈 안에서만 대소문자를 무시한 문자열 검색을 한다. 중국어 의미 검색이나 자동 번역이 아니다.
각 결과는 출처·커밋·파일 위치와 원문 주의사항을 유지한다. 필요한 전후 조건을 read로 이어 읽는다.
보관 파일과 LICENSE/NOTICE는 바꾸지 않았다. 원본을 스킬 발견 경로에 풀거나 실행하는 경로도 추가하지 않았다.

## 실행 가능한 새 예제

[4마디 화성 예제](../plugins/music-producer-kit/skills/music-producer/examples/harmony-study.json)는 Cmaj7-Am7-Dm7-G7의 상성부와 베이스를 독립 트랙으로 적는다.
기존 Mido 도구로 MIDI 생성·재조회가 가능하다. 문서의 보이싱 표와 실제 음표·피치 클래스·길이가 일치하는지 테스트한다.
베이스의 지정된 마디만 바꾼 뒤 화성 트랙과 나머지 이벤트를 보존하는 검사도 포함한다.
이 예제는 기술 검증용 직접 작성 자료다. 완성곡, 특정 아티스트의 구절, 청취 평가를 통과한 곡이 아니다.

## 다음에 남아 있는 상세 검토

악기별 전체 음역·연주법·편성 표, 오케스트라/민속 악기 참고문서, 전체 진행·전조 사례, 심화 대위법·곡식, 신스 음색 레시피는 아직 원본 수준의 상세 이관이 남아 있다.
장르 아홉 분류, 중국어/광둥어 상세 운율, 랩·극음악의 심화 내용, 이미지·서사·라임 사례도 전부 검수 완료로 표시하지 않는다.
이 자료들은 모두 로컬에 남아 있으며 현 작업에 필요한 부분을 찾아 읽을 수 있다. 제목을 보고 버리거나 외부 링크로 대체하지 않는다.

## 검증의 의미

새 테스트는 원본 줄 범위가 실제 존재하는지, 검색·목차가 로컬에서 정확히 작동하는지, 배포에 파일이 들어가는지와 예제 MIDI의 불변 조건을 확인한다.
문서 링크와 검색 테스트를 통과해도 작곡 품질, LLM의 실제 지침 준수, 원어민 가창 자연스러움, Live 연동은 증명되지 않는다.
실제로 관측한 실행 결과는 [STATUS](STATUS.md)에만 기록하고, 미실행 시나리오를 성공으로 바꾸지 않는다.
