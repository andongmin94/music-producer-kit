# Music Producer Kit

자연어 요청을 편집 가능한 음악 작업으로 연결하는 Codex 플러그인. Ableton-first, 장르 제한 없음.

## 개발 상태

첫 패키지를 구성 중입니다. 아직 로컬 Codex 설치, Ableton MCP 연결, 음원 품질 검증을 완료하지 않았습니다.

## 제품 원칙

- 전체 제작과 부분 수정을 요청별로 구분하고, 요청 밖의 기존 작업은 보존합니다.
- 음악이론은 폭넓게 활용하되 특정 화성·비대칭·보컬·장르를 모든 작업에 강제하지 않습니다.
- MIDI와 개별 오디오 소스를 남깁니다. 완성 WAV나 stems만으로 편집 가능한 프로젝트를 대체하지 않습니다.
- 기존 도구를 우선 사용합니다. 구매, 외부 업로드, 비가역적 편집은 별도 승인을 받습니다.
- 검증한 기능과 아직 연결하지 않은 기능을 구분합니다.
- 이 공개 저장소에는 개인 녹음, 유료 샘플, 인증정보, 로컬 경로를 올리지 않습니다.

요구사항과 작업 상태, 원본 지식 선별 내역, 설치 및 검증 절차는 패키지와 함께 기록합니다.
