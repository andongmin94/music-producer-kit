# Development contract

Read README.md, docs/STATUS.md and docs/requirements.md before work.
Read docs/source-selection.md and plugins/music-producer-kit/library/README.md before adapting knowledge.

## Product invariants

- Natural-language music production; Ableton is the first DAW. A simple interface does not require simple music.
- The owner's confirmed lyric/vocal scope is Korean (ko), English (en), Japanese (ja), singly or mixed. Instrumental work remains valid.
- Exclude Chinese/Mandarin/Cantonese production, Chinese-style lyrics and Chinese traditional orchestration. These are not pending integrations or editorial priorities.
- Retain broad non-excluded genres and transferable theory. A Chinese-written general reference is not the same thing as Chinese-specific production. Do not reject Japanese kanji by script.
- Whole-song creation and narrow edits are equally valid; preserve approved material outside the request.
- Preserve all original source bytes, examples, caveats and provenance locally. The original backups are immutable evidence, not automatically installed skills.
- Production reader access excludes the designated specialist modules/files. Archive audit is explicit maintenance evidence access, never a production fallback.
- No submodules, install-time upstream downloads, automatic source updates or remote recovery for missing knowledge.
- Do not restore compulsory asymmetry, chromatic harmony, detuning or repeated-chorus bans.
- Full preservation is not full editorial adaptation, a native-language review or proof of musical quality.
- A MIDI file is not a Live Set. Do not invent MCP tools, device mappings, hearing, save/reopen success or licenses.
- No compatibility layers, speculative backends, custom MIDI codec or redundant configuration. Reuse Mido and the standard library; keep dependencies and CI small.
- This repository is public. No private audio, paid samples, credentials, real machine paths or unpublished songs.
- Preserve upstream LICENSE/NOTICE and third-party rights distinctions. Do not grant a project-wide license without the owner.

## Session continuity

Inspect actual repository state, not a previous plan. Keep main usable with coherent tested increments and no pile of unfinished branches.
Run python tools/check.py and python -m unittest discover -s tests -v before completion claims; record whether results came from this container or remote CI.
Update docs/STATUS.md with actual changes, checks, blockers and the next concrete step before finishing each session.
Never call a failed push successful, a queued run passing or a defined model scenario executed.
Private song session state belongs outside the installed plugin and public repo.
