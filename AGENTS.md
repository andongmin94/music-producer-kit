# Development contract

Read README.md, docs/STATUS.md and docs/requirements.md before work.
Read docs/source-selection.md before adapting or retaining source material.

## Product invariants

- Natural-language music production, Ableton-first. The interface is simple; music need not be simple.
- Lyric/vocal languages are Korean, English and Japanese, singly or mixed. Instrumentals need no lyric language.
- Chinese-specific production content is excluded from both active guidance AND retained source files. Do not preserve excluded originals in backups, hidden views, audit flags or future workstreams.
- Retain transferable theory and in-scope examples with conditions and attribution. Do not mistake Chinese-written general music theory or Japanese kanji for Chinese-specialist production.
- Source URLs are provenance, not dependencies. No upstream downloads, submodules, automatic updates or remote recovery paths.
- One discoverable producer skill; retained source documents are evidence, not operating instructions. No compulsory asymmetry, modulation, detuning or changed choruses.
- Whole-song delegation and narrow edits are equally valid. Protect approved material outside the requested change.
- A MIDI file is not a Live Set. A sample filename is not audio analysis. File tests are not behavioral, listening or native-language evaluation.
- Use actual tools and schemas; never invent MCP actions, hearing, save/reopen success, devices or sample rights.
- Reuse Mido and the standard library. No obsolete compatibility paths, speculative backends or redundant CI/configuration.
- Preserve third-party LICENSE/NOTICE and rights distinctions. Do not grant a project-wide license without the owner.
- No private audio, paid samples, credentials, actual local paths or unpublished songs in this public repo. Purchases and uploads need explicit authorization.

## Session continuity

Inspect actual repository state. Keep main usable with small coherent tested increments.
Run python tools/check.py and python -m unittest discover -s tests -v; record whether validation is local or remote.
Update docs/STATUS.md with actual changes, test results, blockers and the next concrete step before ending each session.
A queued check is not passing; a defined prompt is not an executed model evaluation. Do not claim a failed write succeeded.
Do not repeat resolved genre/voice questions. Song choices vary inside the confirmed scope.
